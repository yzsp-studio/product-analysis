## 🇨🇳 中文

围绕一个具体产品、产品想法或存量方案，产出用于产品进入、定位、竞争策略、上市路径、能力建设与路线图决策的证据型分析报告。它回答的是「值不值得做或发布」「进入哪个细分」「目标用户和市场是否成立」「竞品为何这样设计」「该借鉴、差异化还是放弃」「核心能力与 Roadmap 怎么定」这类问题。支持 0→1、存量产品调整、竞品专项与组合分析，也能把用户研究、市场信息、竞品实测、内部资料和业务约束整合成决策建议。默认交付可独立阅读的飞书云文档，并用正文内 HTML5 block 呈现必要的产品定位图或能力路线图；不用于只罗列功能、直接撰写实施 PRD 或缺少依据时给确定性预测。

### ✨ 能做什么

- 先建立决策简报，锁定这次真正要推动的那个决定
- 选择最短分析路径，不堆材料先把结论问对
- 建立证据底稿：用户研究、市场、竞品实测、内部资料统一归档
- 竞品专项：拆为什么这样设计，给出借鉴/差异化/放弃建议
- 输出产品定位图与能力 Roadmap（正文内 HTML5 图形块）
- 交付可独立阅读的飞书云文档，而不是功能罗列

## 🇬🇧 English

Turns a concrete product, product idea or existing solution into an evidence-based report for entry, positioning, competitive strategy, launch path, capability building and roadmap decisions. It answers whether something is worth building or shipping, which segment to enter, whether target users and market hold up, why competitors designed things that way, what to borrow or differentiate, and how to set core capabilities and roadmap. It covers 0-to-1 work, adjustments to existing products, competitor deep dives and portfolio analysis, integrating user research, market data, hands-on competitor testing, internal material and business constraints. Default delivery is a standalone readable Feishu doc with in-body HTML5 blocks for positioning or capability roadmaps. It is not for listing features, writing implementation PRDs, or giving confident predictions without evidence.

### ✨ What it does

- Starts from a decision brief that names the call to be made
- Picks the shortest analysis path instead of piling up material
- Builds an evidence base from research, market data and competitor tests
- Competitor deep dives explain their design choices and what to copy or skip
- Renders positioning maps and capability roadmaps as in-body HTML5 blocks
- Delivers a standalone readable Feishu doc, never a feature list
